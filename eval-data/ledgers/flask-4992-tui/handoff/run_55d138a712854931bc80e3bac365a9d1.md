## Goal

Add a file mode parameter to flask.Config.from_file()
Python 3.11 introduced native TOML support with the `tomllib` package. This could work nicely with the `flask.Config.from_file()` method as an easy way to load TOML config files:

```python

```

## Changes

**`src/flask/config.py`** — Added a `text: bool = True` parameter to `Config.from_file()`. It opens the file with mode `"r" if text else "rb"`, so binary parsers like `tomllib.load` work:

```python
import tomllib
app.config.from_file("config.toml", load=tomllib.load, text=False)
```

Also updated the docstring example and added a `.. versionchanged:: 2.3` note.

**`docs/config.rst`** — TOML example now uses stdlib `tomllib` with `text=False`.
